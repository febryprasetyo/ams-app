# Frontend Agent Configuration

This file tells Antigravity that it should operate in the **frontend** directory of the project.

- **Root folder**: `frontend/`
- **File extensions to watch**: `.js`, `.jsx`, `.ts`, `.tsx`, `.css`, `.scss`, `.html`
- **Ignored patterns**: `node_modules/`, `dist/`, `build/`, `out/`
